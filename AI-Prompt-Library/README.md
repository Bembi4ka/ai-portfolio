# AI Prompt Library 🤖

Коллекция эффективных промптов для решения рабочих задач с помощью искусственного интеллекта.

## 🎯 Цель проекта

Создать структурированную библиотеку промптов, которые помогают повысить качество работы с AI-инструментами.

Проект демонстрирует навыки:
- Prompt Engineering
- структурирования AI-запросов
- анализа качества ответов
- создания AI-решений для бизнеса

## 🧩 Категории промптов

### Marketing
Промпты для:
- создания контента;
- анализа аудитории;
- генерации маркетинговых идей.

### Customer Support
Промпты для:
- обработки обращений клиентов;
- улучшения ответов поддержки;
- создания базы знаний.

### Productivity
Промпты для:
- планирования задач;
- анализа информации;
- автоматизации рабочих процессов.
